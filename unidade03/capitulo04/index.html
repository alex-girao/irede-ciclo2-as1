Introdução O que dá vida às janelas

Hoje vamos explorar o que dá vida às nossas janelas:

  • Componentes visuais → botões, campos de texto, rótulos e caixas de seleção
  • Eventos → como capturar cliques e entradas de texto para tornar a interface interativa
  • Layouts → como organizar os elementos na tela de maneira profissional
Componentes Visuais no JavaFX Controles
ComponenteDescrição
LabelExibe um texto fixo na tela.
TextFieldCampo para entrada de texto curto.
TextAreaCampo para entrada de texto longo.
ButtonBotão clicável para interações.
CheckBoxCaixa de seleção para múltiplas opções.
RadioButtonBotões de escolha única.

Exemplo de criação de um Label, um TextField e um Button:

Label mensagem = new Label("Bem-vindo ao sistema!"); TextField nomeField = new TextField(); nomeField.setPromptText("Digite seu nome..."); Button enviarButton = new Button("Enviar");
CheckBox, RadioButton e Listas Seleção

CheckBox permite que o usuário selecione múltiplas opções independentes. RadioButton permite escolher uma única opção dentro de um grupo.

// Criando CheckBoxes CheckBox opcao1 = new CheckBox("Aceito os termos"); CheckBox opcao2 = new CheckBox("Receber notificações"); // Criando RadioButtons para seleção de gênero RadioButton masculino = new RadioButton("Masculino"); RadioButton feminino = new RadioButton("Feminino"); // Agrupando os RadioButtons para garantir seleção única ToggleGroup grupoSexo = new ToggleGroup(); masculino.setToggleGroup(grupoSexo); feminino.setToggleGroup(grupoSexo);

Listas: ListView exibe uma lista completa de itens; ComboBox exibe um menu suspenso com opções.

ComboBox<String> opcoes = new ComboBox<>(); opcoes.getItems().addAll("Opção 1", "Opção 2", "Opção 3"); opcoes.setPromptText("Selecione...");
Capturando Eventos dos Componentes Interatividade

Eventos são ações do usuário — como clicar em um botão, digitar texto ou selecionar uma opção — que podem ser capturadas e processadas no código para realizar determinadas funções.

Exemplos de interações capturáveis:

  • Clique em um botão para exibir uma mensagem
  • Digitação em um campo de texto para validar entrada
  • Seleção em um ComboBox para atualizar outro elemento
  • Marcação de CheckBox para ativar/desativar funcionalidades
Exemplos de Captura de Eventos setOnAction & cia.

Clique em botão:

Button botao = new Button("Clique aqui!"); botao.setOnAction(e -> { System.out.println("O botao foi pressionado!"); });

Texto digitado (após clicar em Enviar):

enviarButton.setOnAction(e -> { System.out.println("Nome digitado: " + nomeField.getText()); });

Estado de CheckBoxes (após clicar em Confirmar):

confirmarButton.setOnAction(e -> { System.out.println("Aceitou os termos? " + opcao1.isSelected()); System.out.println("Quer receber notificacoes? " + opcao2.isSelected()); });

Seleção de RadioButton (dentro do ToggleGroup):

selecionarGeneroButton.setOnAction(e -> { RadioButton selecionado = (RadioButton) grupoSexo.getSelectedToggle(); String generoSelecionado = (selecionado != null) ? selecionado.getText() : "Não selecionado"; System.out.println("Genero escolhido: " + generoSelecionado); });
Capturando Eventos de Teclado e Foco Tempo Real

Podemos capturar quando o usuário digita e exibir o texto dinamicamente, a cada tecla solta:

TextField campoTexto = new TextField(); campoTexto.setPromptText("Digite algo..."); campoTexto.setOnKeyReleased(e -> { System.out.println("Texto atual: " + campoTexto.getText()); });
Organizando os Componentes com Layouts 4 tipos principais

Uma interface bem organizada melhora a experiência do usuário. O JavaFX oferece layouts prontos que ajudam a estruturar elementos automaticamente, sem precisar definir posições manualmente.

LayoutDescrição
VBoxOrganiza os elementos verticalmente (um abaixo do outro).
HBoxOrganiza os elementos horizontalmente (um ao lado do outro).
GridPaneOrganiza os elementos em linhas e colunas, como uma tabela.
BorderPaneDivide a interface em cinco regiões: topo, base, centro, esquerda e direita.
Exemplos de Cada Layout Código

VBox — ideal para formulários e menus:

VBox vbox = new VBox(10); // espaçamento de 10px vbox.getChildren().addAll(nomeLabel, nomeField, enviarButton);

HBox — útil para posicionar componentes lado a lado:

HBox hbox = new HBox(10); hbox.getChildren().addAll(nomeLabel, nomeField);

GridPane — organiza como uma tabela, com posições exatas:

GridPane grid = new GridPane(); grid.setHgap(10); grid.setVgap(10); grid.add(nomeLabel, 0, 0); // linha 0, coluna 0 grid.add(nomeField, 1, 0); // linha 0, coluna 1

BorderPane — divide a tela em cinco regiões:

BorderPane borderPane = new BorderPane(); borderPane.setTop(new Label("Cabeçalho")); borderPane.setCenter(new Label("Conteúdo principal")); borderPane.setBottom(new Label("Rodapé"));
Como Escolher o Melhor Layout? Dicas
  • Use VBox quando precisar empilhar elementos verticalmente
  • Use HBox quando precisar posicionar elementos lado a lado
  • Use GridPane quando precisar organizar componentes como uma tabela
  • Use BorderPane quando precisar dividir a tela em seções

🚀 Curiosidades sobre Controles e Layouts
🔗
Todo controle herda de Node
Em JavaFX, Label, Button, TextField e todos os outros controles são subclasses de Node — por isso é possível adicionar qualquer um deles a qualquer layout com o mesmo método getChildren().add().
🎯
Lambdas substituíram classes anônimas
Antes do Java 8, capturar um clique exigia uma classe anônima new EventHandler<ActionEvent>() { ... }. A expressão lambda e -> { ... } usada em setOnAction é só uma forma mais curta de escrever a mesma coisa.
🧲
ToggleGroup não é um componente visual
ToggleGroup não aparece na tela — ele só existe para "lembrar" qual RadioButton está selecionado no momento, garantindo que marcar um desmarque automaticamente os outros do mesmo grupo.
📐
Layouts podem ser aninhados
Nada impede colocar um HBox dentro de um VBox, que por sua vez está dentro do centro de um BorderPane. Interfaces reais quase sempre combinam vários layouts aninhados.
⌨
setOnKeyReleased vs. setOnKeyTyped
setOnKeyReleased dispara quando a tecla é solta (bom para ler o valor já atualizado do campo). Já setOnKeyTyped dispara a cada caractere digitado, incluindo teclas mortas de acentuação.

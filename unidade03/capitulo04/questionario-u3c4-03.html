Implementação em Java 5 questões Nível Básico

Pratique escrevendo código JavaFX real. Cada questão apresenta um problema a ser resolvido com os conceitos deste capítulo: componentes visuais, eventos e layouts. Leia o enunciado, tente resolver por conta própria e depois revele a solução para conferir.

reveladas
1)
Criar um Rótulo e um Campo de Texto
Básico
Crie um Label com a mensagem "Cadastro de Usuário" e um TextField com o texto de instrução "Digite seu e-mail...".
Requisitos
  • Label titulo = new Label("Cadastro de Usuário");
  • TextField emailField = new TextField();
  • Use setPromptText() para definir o texto de instrução
Solução
Label titulo = new Label("Cadastro de Usuário"); TextField emailField = new TextField(); emailField.setPromptText("Digite seu e-mail...");
2)
Capturar Clique e Ler o Campo de Texto
Básico
Usando o emailField do exercício anterior, crie um Button "Cadastrar" que, ao ser clicado, imprime "E-mail cadastrado: " seguido do valor digitado.
Requisitos
  • Button cadastrarButton = new Button("Cadastrar");
  • Use setOnAction(e -> { ... }) com uma expressão lambda
  • Dentro do lambda, use emailField.getText() para ler o valor digitado
Solução
Button cadastrarButton = new Button("Cadastrar"); cadastrarButton.setOnAction(e -> { System.out.println("E-mail cadastrado: " + emailField.getText()); });
Saída esperada no console (após digitar e clicar)
E-mail cadastrado: usuario@exemplo.com
3)
Verificar o Estado de CheckBoxes
Intermediário
Crie duas CheckBox: "Newsletter" e "Promoções". Ao clicar em um botão "Salvar Preferências", imprima no console se cada uma foi marcada.
Requisitos
  • CheckBox newsletter = new CheckBox("Newsletter");
  • CheckBox promocoes = new CheckBox("Promoções");
  • Use isSelected() de cada CheckBox dentro do setOnAction() do botão
Solução
CheckBox newsletter = new CheckBox("Newsletter"); CheckBox promocoes = new CheckBox("Promoções"); Button salvarButton = new Button("Salvar Preferências"); salvarButton.setOnAction(e -> { System.out.println("Newsletter: " + newsletter.isSelected()); System.out.println("Promoções: " + promocoes.isSelected()); });
4)
Agrupar RadioButtons e Capturar a Seleção
Intermediário
Crie três RadioButton para um plano de assinatura ("Básico", "Intermediário", "Premium"), agrupe-os em um ToggleGroup e, ao clicar em um botão, imprima qual plano foi escolhido.
Requisitos
  • Crie os três RadioButton e um ToggleGroup grupoPlano
  • Associe cada botão ao grupo com setToggleGroup(grupoPlano)
  • No clique, use (RadioButton) grupoPlano.getSelectedToggle() para descobrir a escolha
  • Se nada estiver selecionado, imprima "Nenhum plano selecionado"
Solução
RadioButton basico = new RadioButton("Básico"); RadioButton intermed = new RadioButton("Intermediário"); RadioButton premium = new RadioButton("Premium"); ToggleGroup grupoPlano = new ToggleGroup(); basico.setToggleGroup(grupoPlano); intermed.setToggleGroup(grupoPlano); premium.setToggleGroup(grupoPlano); Button escolherButton = new Button("Escolher Plano"); escolherButton.setOnAction(e -> { RadioButton selecionado = (RadioButton) grupoPlano.getSelectedToggle(); String plano = (selecionado != null) ? selecionado.getText() : "Nenhum plano selecionado"; System.out.println("Plano escolhido: " + plano); });
5)
Programa Completo — Formulário com VBox
Intermediário
Junte os componentes das questões anteriores em uma aplicação JavaFX completa, organizados verticalmente em um VBox, exibida em uma Scene e um Stage.
Requisitos
  • Crie VBox layout = new VBox(10); e adicione o título, o campo de e-mail e o botão de cadastro
  • Crie Scene scene = new Scene(layout, 320, 200);
  • Configure o título da janela e chame show()
Solução
import javafx.application.Application; import javafx.scene.Scene; import javafx.scene.control.Button; import javafx.scene.control.Label; import javafx.scene.control.TextField; import javafx.scene.layout.VBox; import javafx.stage.Stage; public class Cadastro extends Application { @Override public void start(Stage primaryStage) { Label titulo = new Label("Cadastro de Usuário"); TextField emailField = new TextField(); emailField.setPromptText("Digite seu e-mail..."); Button cadastrarButton = new Button("Cadastrar"); cadastrarButton.setOnAction(e -> { System.out.println("E-mail cadastrado: " + emailField.getText()); }); VBox layout = new VBox(10); layout.getChildren().addAll(titulo, emailField, cadastrarButton); Scene scene = new Scene(layout, 320, 200); primaryStage.setTitle("Cadastro"); primaryStage.setScene(scene); primaryStage.show(); } public static void main(String[] args) { launch(args); } }
💡 Repare que o VBox aceita qualquer combinação de controles na mesma lista — não importa se são Label, TextField ou Button, todos são Node.

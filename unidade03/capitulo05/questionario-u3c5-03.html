Implementação em Java 5 questões Nível Básico

Pratique escrevendo código FXML, Controller e CSS reais. Cada questão apresenta um problema a ser resolvido com os conceitos deste capítulo: FXML, @FXML, fx:id, onAction e estilização com CSS. Leia o enunciado, tente resolver por conta própria e depois revele a solução para conferir.

0/5
reveladas
1)
Criar um FXML Básico
Básico
Crie um arquivo Interface.fxml com um AnchorPane de 320x150, contendo um Button com o texto "Salvar" que aciona o método salvarDados do Controller.
Requisitos
  • Declare xmlns:fx e fx:controller apontando para o pacote e classe do Controller
  • Defina prefWidth="320" e prefHeight="150"
  • O Button deve ter onAction="#salvarDados"
Solução
<?xml version="1.0" encoding="UTF-8"?> <?import javafx.scene.control.Button?> <?import javafx.scene.layout.AnchorPane?> <AnchorPane xmlns:fx="http://javafx.com/fxml" fx:controller="meupacote.Controller" prefWidth="320" prefHeight="150"> <Button text="Salvar" layoutX="110" layoutY="60" onAction="#salvarDados" /> </AnchorPane>
2)
Criar o Controller Correspondente
Básico
Crie a classe Controller referenciada no exercício anterior, com o método salvarDados() imprimindo "Dados salvos!" no console.
Requisitos
  • A classe deve pertencer ao pacote meupacote
  • O método deve ser anotado com @FXML
  • O nome do método deve ser exatamente salvarDados, igual ao referenciado no FXML
Solução
package meupacote; import javafx.fxml.FXML; public class Controller { @FXML public void salvarDados() { System.out.println("Dados salvos!"); } }
Saída esperada no console (após clicar em "Salvar")
Dados salvos!
3)
Carregar o FXML na Classe Principal
Intermediário
Crie a classe principal MinhaApp, que estende Application e usa FXMLLoader para carregar Interface.fxml, exibindo a janela com o título "Formulário FXML".
Requisitos
  • Use FXMLLoader.load(getClass().getResource("Interface.fxml"))
  • Crie a Scene a partir do Parent retornado
  • Configure o título, a Scene e chame show()
Solução
package meupacote; import javafx.application.Application; import javafx.fxml.FXMLLoader; import javafx.scene.Parent; import javafx.scene.Scene; import javafx.stage.Stage; public class MinhaApp extends Application { @Override public void start(Stage stage) throws Exception { Parent root = FXMLLoader.load(getClass().getResource("Interface.fxml")); Scene scene = new Scene(root); stage.setTitle("Formulário FXML"); stage.setScene(scene); stage.show(); } public static void main(String[] args) { launch(args); } }
4)
Estilizar o Botão com CSS
Intermediário
Crie um arquivo style.css que deixe o botão "Salvar" com fundo azul (#3498db), texto branco e cantos arredondados, e conecte-o ao FXML da questão 1.
Requisitos
  • No style.css, use o seletor .button
  • Defina -fx-background-color, -fx-text-fill e -fx-background-radius
  • No AnchorPane raiz do FXML, adicione stylesheets="@style.css"
Solução
/* style.css */ .button { -fx-background-color: #3498db; -fx-text-fill: white; -fx-background-radius: 8; -fx-font-weight: bold; -fx-cursor: hand; }
<AnchorPane xmlns:fx="http://javafx.com/fxml" fx:controller="meupacote.Controller" prefWidth="320" prefHeight="150" stylesheets="@style.css"> <Button text="Salvar" layoutX="110" layoutY="60" onAction="#salvarDados" /> </AnchorPane>
5)
Formulário Completo com fx:id
Intermediário
Amplie o formulário: adicione um TextField com fx:id="tituloField" antes do botão, e faça salvarDados() imprimir "Salvando: " seguido do valor digitado.
Requisitos
  • Adicione <TextField fx:id="tituloField" .../> ao FXML
  • No Controller, declare @FXML private TextField tituloField;
  • Use tituloField.getText() dentro de salvarDados()
Solução
<?import javafx.scene.control.TextField?> <AnchorPane xmlns:fx="http://javafx.com/fxml" fx:controller="meupacote.Controller" prefWidth="320" prefHeight="150" stylesheets="@style.css"> <TextField fx:id="tituloField" layoutX="40" layoutY="30" /> <Button text="Salvar" layoutX="110" layoutY="70" onAction="#salvarDados" /> </AnchorPane>
package meupacote; import javafx.fxml.FXML; import javafx.scene.control.TextField; public class Controller { @FXML private TextField tituloField; @FXML public void salvarDados() { System.out.println("Salvando: " + tituloField.getText()); } }
Saída esperada no console (após digitar e clicar em "Salvar")
Salvando: Relatório Mensal
💡 Note como fx:id="tituloField" no FXML e @FXML private TextField tituloField; no Controller precisam ter exatamente o mesmo nome — é assim que o FXMLLoader faz a injeção automática.

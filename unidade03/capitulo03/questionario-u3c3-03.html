Implementação em Java 5 questões Nível Básico

Pratique escrevendo código JavaFX real. Cada questão apresenta um problema a ser resolvido com os conceitos deste capítulo: Application, Stage, Scene e eventos de clique. Leia o enunciado, tente resolver por conta própria e depois revele a solução para conferir.

reveladas
1)
Criar a Classe Principal da Aplicação
Básico
Crie o esqueleto de uma aplicação JavaFX chamada MinhaApp, com o método start() vazio e o main() chamando launch().
Requisitos
  • A classe deve estender javafx.application.Application
  • Sobrescreva public void start(Stage primaryStage) (pode deixar o corpo vazio por enquanto)
  • No main(String[] args), chame launch(args)
Solução
import javafx.application.Application; import javafx.stage.Stage; public class MinhaApp extends Application { @Override public void start(Stage primaryStage) { // interface será montada aqui } public static void main(String[] args) { launch(args); } }
2)
Criar um Botão em um Layout
Básico
Dentro de start(), crie um Button com o texto "Enviar" e adicione-o a um StackPane.
Requisitos
  • Crie Button botao = new Button("Enviar");
  • Crie StackPane layout = new StackPane();
  • Adicione o botão ao layout com layout.getChildren().add(botao);
Solução
import javafx.scene.control.Button; import javafx.scene.layout.StackPane; @Override public void start(Stage primaryStage) { Button botao = new Button("Enviar"); StackPane layout = new StackPane(); layout.getChildren().add(botao); }
3)
Criar a Scene e Exibir o Stage
Básico
Usando o layout do exercício anterior, crie uma Scene de 400x250 pixels, defina o título da janela como "Formulário" e exiba o Stage.
Requisitos
  • Crie Scene scene = new Scene(layout, 400, 250);
  • Chame primaryStage.setTitle("Formulário");
  • Chame primaryStage.setScene(scene); e primaryStage.show();
Solução
import javafx.scene.Scene; @Override public void start(Stage primaryStage) { Button botao = new Button("Enviar"); StackPane layout = new StackPane(); layout.getChildren().add(botao); Scene scene = new Scene(layout, 400, 250); primaryStage.setTitle("Formulário"); primaryStage.setScene(scene); primaryStage.show(); }
4)
Adicionar um Evento de Clique
Intermediário
Faça o botão "Enviar" imprimir "Formulário enviado!" no console quando clicado, reproduzindo o fluxo de eventos visto no resumo: usuário clica → sistema detecta o evento → aplicação responde.
Requisitos
  • Use botao.setOnAction(event -> { ... });
  • Dentro do lambda, chame System.out.println("Formulário enviado!");
Solução
Button botao = new Button("Enviar"); botao.setOnAction(event -> { System.out.println("Formulário enviado!"); });
Saída esperada no console (após clicar no botão)
Formulário enviado!
5)
Programa Completo — Formulário JavaFX
Intermediário
Junte tudo dos exercícios anteriores em um único programa: uma aplicação JavaFX completa com botão, layout, Scene, Stage e evento de clique.
Requisitos
  • Combine as soluções das questões 1 a 4 em uma única classe MinhaApp
  • Ao clicar em "Enviar", o console deve exibir "Formulário enviado!"
Solução
import javafx.application.Application; import javafx.scene.Scene; import javafx.scene.control.Button; import javafx.scene.layout.StackPane; import javafx.stage.Stage; public class MinhaApp extends Application { @Override public void start(Stage primaryStage) { Button botao = new Button("Enviar"); botao.setOnAction(event -> { System.out.println("Formulário enviado!"); }); StackPane layout = new StackPane(); layout.getChildren().add(botao); Scene scene = new Scene(layout, 400, 250); primaryStage.setTitle("Formulário"); primaryStage.setScene(scene); primaryStage.show(); } public static void main(String[] args) { launch(args); } }
Saída esperada no console (após clicar em "Enviar")
Formulário enviado!
💡 Não esqueça de configurar a biblioteca JavaFX em Compile e Run nas propriedades do projeto, e as VM Options com --module-path e --add-modules javafx.controls,javafx.fxml, como visto no resumo.

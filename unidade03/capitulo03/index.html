O que é uma Interface Gráfica? GUI

Interface Gráfica do Usuário (GUI — Graphical User Interface) é uma maneira visual e interativa de um usuário se comunicar com um software.

Principais características: permite interação com elementos visuais (botões, janelas, menus) · substitui interfaces baseadas em texto (como terminais e consoles) · torna o software mais acessível e intuitivo para usuários comuns.

Exemplos de GUI: sistemas operacionais (Windows, macOS, Linux) · navegadores (Chrome, Firefox) · softwares de edição (Photoshop, Word).

Estrutura de uma Interface Gráfica Elementos

Uma interface gráfica é composta por elementos visuais, organizados em layouts e gerenciados por um sistema de eventos que responde às ações do usuário.

Elementos principais:

  • Janelas (Frames) → área onde os elementos gráficos são exibidos
  • Botões (Buttons) → permitem interação, acionando ações
  • Campos de texto (TextFields) → entrada de informações pelo usuário
  • Menus e barras de ferramentas → facilitam o acesso a funções
Como Funciona uma GUI? Sistema de Eventos

Exemplo prático: quando clicamos em um botão "Salvar", um evento é acionado que grava os dados no banco e exibe uma mensagem de sucesso.

Tipos de Interfaces Gráficas em Java Swing vs. JavaFX

Existem diversas tecnologias para criar GUI. Algumas das principais para Java são:

  • Swing → biblioteca tradicional do Java para GUI, mas com visual mais antigo
  • JavaFX → evolução moderna do Swing, mais flexível e com suporte a gráficos avançados

O que é o JavaFX? Biblioteca Gráfica

O JavaFX é uma biblioteca moderna para criação de interfaces gráficas em Java, que substitui o antigo Swing.

JavaFX usa CSS e FXML para estilização e estrutura, tem melhor performance e suporta gráficos avançados. Se você quer criar interfaces modernas, dinâmicas e responsivas, o JavaFX é a melhor escolha.

Configurando o Ambiente NetBeans + Gluon SDK

Para usar JavaFX em projetos Java "puro" (sem Maven/Gradle), é preciso baixar o SDK e registrá-lo manualmente como biblioteca da IDE:

1
Baixar o JDK JavaFX — acesse gluonhq.com/products/javafx e baixe o SDK correspondente ao seu sistema operacional. Importante: se o JDK instalado for a versão 21, baixe o JavaFX 21 (a versão do SDK deve ser compatível com a do JDK).
2
No NetBeans, acesse Tools → Libraries e crie uma New Library (ex: JavaFx24).
3
Em Classpath, clique em Add JAR/Folder e selecione todos os arquivos .jar da pasta lib do SDK extraído (javafx.base, javafx.controls, javafx.fxml, javafx.graphics, etc.).
4
Crie o projeto como Java with Ant → JavaFX, abra Properties → Libraries e adicione a biblioteca criada tanto em Compile quanto em Run.
5
Em Build → Compiling, desative a opção Compile on Save.
6
Em Run → VM Options, adicione: --module-path "<caminho>\javafx-sdk\lib" --add-modules javafx.controls,javafx.fxml, substituindo o caminho pelo local onde está a biblioteca extraída.
Estrutura Básica de uma Aplicação JavaFX 4 componentes

Principais componentes em uma estrutura básica de uma aplicação JavaFX:

  • Application → classe principal que inicializa o JavaFX
  • start(Stage primaryStage) → método que define a interface gráfica
  • Stage → a janela principal da aplicação
  • Scene → define os elementos gráficos dentro da janela
Primeira Aplicação JavaFX Exemplo completo
package ex38javafxbasico; import javafx.application.Application; import javafx.scene.Scene; import javafx.scene.control.Button; import javafx.scene.layout.StackPane; import javafx.stage.Stage; public class Ex38JavaFxBasico extends Application { @Override public void start(Stage primaryStage) { Button botao = new Button("Clique aqui!"); StackPane layout = new StackPane(); layout.getChildren().add(botao); Scene scene = new Scene(layout, 300, 200); primaryStage.setTitle("Minha primeira aplicação JavaFX"); primaryStage.setScene(scene); primaryStage.show(); } public static void main(String[] args) { launch(args); } }

Ao executar, uma janela de 300x200 pixels é exibida, com o título "Minha primeira aplicação JavaFX" e um botão "Clique aqui!" centralizado.

🚀 Curiosidades sobre JavaFX
📅
JavaFX já foi parte do JDK
Até o Java 8, o JavaFX vinha embutido no próprio JDK. A partir do Java 11, ele foi separado em um módulo independente (o SDK da Gluon usado neste capítulo) — por isso hoje é preciso baixá-lo à parte.
🎨
FXML separa design de lógica
Assim como HTML separa estrutura de uma página do seu comportamento em JavaScript, o FXML permite descrever a interface JavaFX em um arquivo XML separado da classe Java — um padrão muito próximo do MVC.
🎭
CSS de verdade, com seletores próprios
O JavaFX usa arquivos .css quase idênticos ao CSS da web, mas com propriedades prefixadas por -fx-, como -fx-background-color.
🖥
Um Stage pode ter várias Scenes
Uma mesma janela (Stage) pode trocar de Scene em tempo de execução — é assim que se implementam trocas de "tela" dentro de uma mesma janela, sem precisar abrir uma nova.
⚡
Por que desativar "Compile on Save"?
Com módulos JavaFX carregados via VM Options (--module-path), recompilar automaticamente a cada salvamento pode gerar conflitos de classpath no NetBeans — por isso o material recomenda desativar essa opção para projetos JavaFX feitos com Ant.

1)
Criar uma Classe Genérica
Básico
Crie uma classe genérica chamada Caixa<T> que armazena um item de qualquer tipo. Em seguida, no main, crie uma Caixa<String>, guarde um valor e imprima o item guardado.
Requisitos
  • Declare a classe como public class Caixa<T> com atributo privado T item
  • Implemente void guardar(T item) e T abrir()
  • No main, crie Caixa<String> caixa = new Caixa<>();
  • Guarde o valor "Livro" e imprima o resultado de abrir()
Solução
public class Caixa<T> { private T item; public void guardar(T item) { this.item = item; } public T abrir() { return item; } } public class Ex01ClasseGenerica { public static void main(String[] args) { Caixa<String> caixa = new Caixa<>(); caixa.guardar("Livro"); System.out.println("Item guardado: " + caixa.abrir()); } }
Saída esperada no console
Item guardado: Livro
2)
Reutilizar a Caixa<T> com Outro Tipo
Básico
Usando a mesma classe Caixa<T> do exercício anterior, crie no main uma segunda caixa que armazena um número inteiro, provando que a classe é reutilizável para qualquer tipo.
Requisitos
  • Crie Caixa<Integer> caixa2 = new Caixa<>();
  • Guarde o valor 123 com guardar()
  • Imprima o resultado de abrir() com uma mensagem descritiva
Solução
public class Ex02CaixaReutilizavel { public static void main(String[] args) { Caixa<Integer> caixa2 = new Caixa<>(); caixa2.guardar(123); System.out.println("Item guardado: " + caixa2.abrir()); } }
Saída esperada no console
Item guardado: 123
3)
Criar um Método Genérico
Básico
Crie uma classe Util com um método genérico estático imprimir, capaz de receber e imprimir qualquer tipo de valor. Chame-o com três tipos diferentes.
Requisitos
  • Declare public static <T> void imprimir(T valor) na classe Util
  • Chame Util.imprimir("Olá, mundo!"), Util.imprimir(100) e Util.imprimir(3.14)
Solução
public class Util { public static <T> void imprimir(T valor) { System.out.println(valor); } } public class Ex03MetodoGenerico { public static void main(String[] args) { Util.imprimir("Olá, mundo!"); // String Util.imprimir(100); // Integer Util.imprimir(3.14); // Double } }
Saída esperada no console
Olá, mundo! 100 3.14
4)
Criar uma Interface Genérica
Intermediário
Crie uma interface genérica Repositorio<T> que define um contrato de operações CRUD (Create, Read, Update, Delete) reutilizável para qualquer tipo de entidade.
Requisitos
  • Declare public interface Repositorio<T>
  • Inclua os métodos void salvar(T entidade), T buscarPorId(int id), void atualizar(T entidade), void deletar(int id) e List<T> listarTodos()
Solução
import java.util.List; public interface Repositorio<T> { void salvar(T entidade); // Criar ou salvar uma entidade T buscarPorId(int id); // Buscar por ID void atualizar(T entidade); // Atualizar dados void deletar(int id); // Remover entidade List<T> listarTodos(); // Retornar lista de todas as entidades }
💡 Uma interface sozinha não roda — ela só define o contrato. O próximo exercício implementa esse contrato para uma entidade concreta.
5)
Implementar Repositorio<T> para Produto
Intermediário
Crie uma classe Produto com um atributo nome e implemente RepositorioDeProdutos, que implementa Repositorio<Produto>. No main, salve dois produtos e liste todos.
Requisitos
  • Classe Produto com String nome, construtor e getNome()
  • RepositorioDeProdutos implements Repositorio<Produto>, guardando os itens em uma List<Produto>
  • Implemente ao menos salvar() e listarTodos() (os demais métodos do contrato podem ficar simples)
  • No main, salve "Caderno" e "Caneta", depois imprima a lista
Solução
class Produto { private String nome; public Produto(String nome) { this.nome = nome; } public String getNome() { return nome; } } import java.util.ArrayList; import java.util.List; public class RepositorioDeProdutos implements Repositorio<Produto> { private List<Produto> produtos = new ArrayList<>(); @Override public void salvar(Produto produto) { produtos.add(produto); } @Override public Produto buscarPorId(int id) { return produtos.get(id); } @Override public void atualizar(Produto produto) { /* omitido */ } @Override public void deletar(int id) { produtos.remove(id); } @Override public List<Produto> listarTodos() { return produtos; } } public class Ex05Repositorio { public static void main(String[] args) { RepositorioDeProdutos repo = new RepositorioDeProdutos(); repo.salvar(new Produto("Caderno")); repo.salvar(new Produto("Caneta")); for (Produto p : repo.listarTodos()) { System.out.println("Produto: " + p.getNome()); } } }
Saída esperada no console
Produto: Caderno Produto: Caneta

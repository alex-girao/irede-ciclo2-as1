Wildcard Simples com List<?>
Básico
Crie um método estático imprimirLista que recebe uma List<?> e imprime cada elemento. Teste-o com uma lista de String e uma de Integer.
Requisitos
  • Declare public static void imprimirLista(List<?> lista) numa classe Util
  • Percorra a lista tratando cada item como Object
  • Crie List<String> e List<Integer> com Arrays.asList() e chame o método para ambas
Solução
import java.util.Arrays; import java.util.List; public class Util { public static void imprimirLista(List<?> lista) { for (Object item : lista) { System.out.println(item); } } } public class Ex01Wildcard { public static void main(String[] args) { List<String> listaStrings = Arrays.asList("Java", "Generics", "Wildcard"); List<Integer> listaInteiros = Arrays.asList(10, 20, 30); Util.imprimirLista(listaStrings); Util.imprimirLista(listaInteiros); } }
Saída esperada no console
Java Generics Wildcard 10 20 30
2)
Leitura Segura com ? extends T
Básico
Crie as classes Pessoa e Funcionario (que herda de Pessoa), e um método mostrarNomes que aceita uma List<? extends Pessoa>. Teste com uma lista de cada tipo.
Requisitos
  • Pessoa com String nome, construtor e getNome()
  • Funcionario extends Pessoa, chamando super(nome) no construtor
  • public static void mostrarNomes(List<? extends Pessoa> pessoas)
  • Chame com uma List<Pessoa> e uma List<Funcionario>
Solução
public class Pessoa { private String nome; public Pessoa(String nome) { this.nome = nome; } public String getNome() { return nome; } } public class Funcionario extends Pessoa { public Funcionario(String nome) { super(nome); } } import java.util.Arrays; import java.util.List; public class Util { public static void mostrarNomes(List<? extends Pessoa> pessoas) { for (Pessoa p : pessoas) { System.out.println(p.getNome()); } } } public class Ex02ExtendsT { public static void main(String[] args) { List<Pessoa> pessoas = Arrays.asList(new Pessoa("Ana")); List<Funcionario> funcionarios = Arrays.asList(new Funcionario("Carlos")); Util.mostrarNomes(pessoas); Util.mostrarNomes(funcionarios); } }
Saída esperada no console
Ana Carlos
3)
Escrita Segura com ? super T
Intermediário
Usando as mesmas classes Pessoa e Funcionario do exercício anterior, crie um método adicionarPessoa que recebe uma List<? super Funcionario> e adiciona um novo Funcionario nela.
Requisitos
  • public static void adicionarPessoa(List<? super Funcionario> lista)
  • Dentro do método, adicione new Funcionario("Novo Funcionario") à lista
  • No main, crie uma List<Pessoa> (com ArrayList) e passe-a para o método
  • Imprima os nomes de todos os elementos da lista após a chamada
Solução
import java.util.List; public class Util { public static void adicionarPessoa(List<? super Funcionario> lista) { lista.add(new Funcionario("Novo Funcionario")); } } import java.util.ArrayList; import java.util.List; public class Ex03SuperT { public static void main(String[] args) { List<Pessoa> listaPessoas = new ArrayList<>(); Util.adicionarPessoa(listaPessoas); for (Pessoa p : listaPessoas) { System.out.println("Nome: " + p.getNome()); } } }
Saída esperada no console
Nome: Novo Funcionario
4)
Soma Genérica com List<? extends Number>
Intermediário
Crie uma classe MathUtil com um método calcularSoma que recebe uma List<? extends Number> e retorna a soma de todos os valores. Teste com listas de tipos numéricos diferentes.
Requisitos
  • public static double calcularSoma(List<? extends Number> numeros)
  • Use n.doubleValue() para converter cada elemento antes de somar
  • Teste com List<Integer> [10, 20, 30, 40] e List<Double> [1.5, 2.5, 3.5]
Solução
import java.util.List; public class MathUtil { public static double calcularSoma(List<? extends Number> numeros) { double soma = 0; for (Number n : numeros) { soma += n.doubleValue(); } return soma; } } import java.util.Arrays; import java.util.List; public class Ex04MathUtil { public static void main(String[] args) { List<Integer> listaInteiros = Arrays.asList(10, 20, 30, 40); List<Double> listaDoubles = Arrays.asList(1.5, 2.5, 3.5); System.out.println("Soma de Inteiros: " + MathUtil.calcularSoma(listaInteiros)); System.out.println("Soma de Doubles: " + MathUtil.calcularSoma(listaDoubles)); } }
Saída esperada no console
Soma de Inteiros: 100.0 Soma de Doubles: 7.5
5)
Combinando extends e super (PECS)
Avançado
Crie um método copiar que recebe uma lista de origem (? extends T, só leitura) e uma lista de destino (? super T, só escrita), copiando todos os elementos da origem para o destino — o mesmo princípio usado por Collections.copy().
Requisitos
  • public static <T> void copiar(List<? extends T> origem, List<? super T> destino)
  • Percorra origem e chame destino.add(item) para cada elemento
  • Teste copiando uma List<Funcionario> para uma List<Pessoa> vazia
Solução
import java.util.List; public class Util { public static <T> void copiar(List<? extends T> origem, List<? super T> destino) { for (T item : origem) { // origem: só produz (lê) destino.add(item); // destino: só consome (escreve) } } } import java.util.ArrayList; import java.util.Arrays; import java.util.List; public class Ex05Pecs { public static void main(String[] args) { List<Funcionario> origem = Arrays.asList(new Funcionario("Carlos"), new Funcionario("Ana")); List<Pessoa> destino = new ArrayList<>(); Util.<Funcionario>copiar(origem, destino); for (Pessoa p : destino) { System.out.println(p.getNome()); } } }
Saída esperada no console
Carlos Ana
💡 PECS: Producer Extends, Consumer Super — origem "produz" itens para leitura (extends), destino "consome" itens que você escreve (super).

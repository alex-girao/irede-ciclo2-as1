## Capítulos

### Capítulo 01 — Introdução ao Generics
Conteúdo: Motivação para uso de Generics · Criação de Classes Genéricas (`Caixa<T>`) · Métodos Genéricos · Interfaces Genéricas (`Repositorio<T>`)

Baseado no material de apoio `Java - U1C1O1S1 - Slide.pdf`.

### Capítulo 02 — Wildcards e Tipos Limitados
Conteúdo: Uso de curingas (`?`) · `? extends T` · `? super T` · Aplicações práticas com Generics e a API Collections

Baseado no material de apoio `Java - U1C2O1S1 - Slide.pdf`.

### Capítulo 03 — Introdução ao JavaFX e Estrutura de Aplicações
Conteúdo: Interfaces gráficas (GUI) · Swing vs. JavaFX · Configuração do ambiente (Gluon SDK + NetBeans) · Estrutura de uma aplicação JavaFX (`Application`, `start(Stage)`, `Stage`, `Scene`) · Primeira aplicação JavaFX

Baseado no material de apoio `Java - U2C1O1S1 - Slide.pdf`.

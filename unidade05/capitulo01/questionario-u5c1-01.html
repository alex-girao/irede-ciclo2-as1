🧪 Testes de Software 🟣 Fácil ⏱ ~4 min
0 / 8 respondidas
01
Teste de software é o processo de verificar apenas se o código compila sem erros.
02
O teste de unidade testa métodos ou funções individuais, isoladas do restante do sistema.
03
O teste de integração verifica a interação entre dois ou mais módulos do sistema.
04
O teste de aceitação é executado apenas pelos desenvolvedores, nunca pelo cliente final.
05
O teste de sistema avalia o funcionamento do sistema completo e integrado.
06
Testes funcionais avaliam aspectos como performance e escalabilidade do sistema.
07
Um teste que mede o tempo de resposta ao acessar uma página é considerado um teste não funcional.
08
Identificar falhas e inconsistências no sistema faz parte do processo de teste de software.

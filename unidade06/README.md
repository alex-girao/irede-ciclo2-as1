## Capítulos

### Capítulo 01 — Apresentação do Projeto (Intermediário)
Conteúdo: continuação dos projetos práticos iniciados no módulo anterior (fase console + POO), evoluindo para a fase intermediária. Apresenta os três projetos disponíveis — **Projeto 1: TaskManager** (Gerenciador de Tarefas), **Projeto 2: FinTrack** (Finanças Pessoais) e **Projeto 3: Agenda de Contatos** — com o que já foi construído e o que deve ser feito a partir de agora: Generics, Interface Gráfica com JavaFX, telas em FXML/Scene Builder, acesso a Banco de Dados com JDBC e Testes de Software com JUnit. Esta é a 2ª de 3 entregas previstas para o curso.

Baseado no material de apoio `Java - U5C1O1S1 - Slide.pdf`.

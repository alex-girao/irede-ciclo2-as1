01
git stash guarda temporariamente as alterações não commitadas e limpa o working directory, permitindo trocar de branch sem perder o trabalho.
02
git revert <hash> apaga o commit indicado do histórico permanentemente.
03
git reset --hard HEAD~1 move o HEAD para o commit anterior e descarta permanentemente todas as alterações do working directory e staging.
04
git reset --soft HEAD~1 desfaz o último commit mas mantém as alterações no staging area, prontas para um novo commit.
05
O git stash funciona como uma pilha (stack): você pode guardar vários estados e recuperar qualquer um deles.
06
O git revert é o método mais seguro para desfazer commits em branches compartilhadas (públicas), pois não reescreve o histórico.
07
O modo padrão do git reset (sem flags) é o --hard, que descarta todas as alterações locais.
08
O comando git tag -a v1.0 -m "Release 1.0" cria uma annotated tag, que inclui metadados como autor, data e mensagem.
09
O git reflog registra todo o histórico de movimentações do HEAD, podendo ser usado para recuperar commits perdidos após um git reset --hard.
10
git stash pop recupera o stash mais recente e o remove da pilha de stashes.

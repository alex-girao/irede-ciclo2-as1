O comando git init é usado para clonar um repositório remoto para a máquina local.
03
A pasta oculta .git/ criada pelo git init contém todo o histórico de commits, branches e configurações do repositório.
04
O HEAD no Git é um ponteiro especial que normalmente aponta para o último commit da branch ativa.
05
O comando git status é usado para criar um novo commit com as alterações da Staging Area.
06
A Staging Area (também chamada de Index) é a área onde as alterações são preparadas antes de serem registradas permanentemente em um commit.
07

08

O comando git commit --amend é seguro de usar mesmo após fazer git push, pois não altera o histórico remoto.

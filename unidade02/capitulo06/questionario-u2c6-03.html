01
DeclararPacote package
Crie uma classe chamada Produto que pertence ao pacote com.loja.model. A classe deve ter um atributo nome do tipo String e um atributo preco do tipo double, ambos privados, com getters e setters.
Requisitos
Declarar package com.loja.model; como primeira linha do arquivo
Atributos private String nome e private double preco
Getters e setters para ambos os atributos
Produto.java — com/loja/model/
package com.loja.model; public class Produto { private String nome; private double preco; public String getNome() { return nome; } public void setNome(String nome) { this.nome = nome; } public double getPreco() { return preco; } public void setPreco(double preco) { this.preco = preco; } }
Estrutura no sistema de arquivos
src/ └─ com/ └─ loja/ └─ model/ └─ Produto.java

Requisitos
Declarar package com.loja;

04
CriarService service
Crie a classe ProdutoService no pacote com.loja.service. Ela deve importar Produto do pacote com.loja.model e ter um método exibirProduto(Produto p) que imprime o nome e preço do produto.
Requisitos
Declarar pacote com.loja.service
Importar com.loja.model.Produto
Método public void exibirProduto(Produto p)
ProdutoService.java — com/loja/service/
package com.loja.service; import com.loja.model.Produto; public class ProdutoService { public void exibirProduto(Produto p) { System.out.println("=== Produto ==="); System.out.println("Nome: " + p.getNome()); System.out.println("Preço: R$ " + p.getPreco()); } }

Produto p = new Produto(); p.setNome("Mouse"); p.setPreco(80.0); new ProdutoService().exibirProduto(p); // === Produto === // Nome: Mouse // Preço: R$ 80.0

07
ImportWildcard import *
Crie a classe Relatorio no pacote com.loja que usa ArrayList e Date do pacote java.util. Demonstre o uso do import com wildcard (*) para importar todas as classes do pacote.
Requisitos
Usar import java.util.* para importar todo o pacote
Criar um ArrayList<String> e adicionar itens
Criar um objeto Date e exibir a data atual
Relatorio.java — com/loja/
package com.loja; import java.util.*; // importa todas as classes de java.util public class Relatorio { public static void main(String[] args) { ArrayList<String> itens = new ArrayList<>(); itens.add("Teclado"); itens.add("Mouse"); itens.add("Monitor"); Date hoje = new Date(); System.out.println("Relatório gerado em: " + hoje); System.out.println("Produtos: " + itens); } }
Observação sobre wildcard
// import java.util.* NÃO importa subpacotes! // java.util.concurrent.locks.Lock precisaria de: // import java.util.concurrent.locks.Lock; // Wildcard pode dificultar leitura — prefira imports específicos.

ConflitoDatas.java
package com.loja; import java.util.Date; // java.util.Date importada pelo nome simples public class ConflitoDatas { public static void main(String[] args) { // java.util.Date — usada pelo nome simples Date agora = new Date(); System.out.println("Data atual: " + agora); // java.sql.Date — precisa do nome qualificado completo java.sql.Date dataSQL = new java.sql.Date(agora.getTime()); System.out.println("Data SQL: " + dataSQL); } }

09
EstruturaMultiCamadas avançado
Monte a estrutura completa de um sistema de clientes com pacotes separados por camada: model (entidade Cliente), service (ClienteService com método cadastrar), exceptions (ClienteJaCadastradoException) e main (classe principal que usa tudo).
Requisitos
Pacote base: com.sistema
Cada camada no subpacote correto (model, service, exceptions)
Classe Main usando ClienteService com try-catch
model/Cliente.java
package com.sistema.model; public class Cliente { private String nome; private String cpf; public Cliente(String nome, String cpf) { this.nome = nome; this.cpf = cpf; } public String getNome() { return nome; } public String getCpf() { return cpf; } }
exceptions/ClienteJaCadastradoException.java
package com.sistema.exceptions; public class ClienteJaCadastradoException extends Exception { public ClienteJaCadastradoException(String msg) { super(msg); } }
service/ClienteService.java
package com.sistema.service; import com.sistema.model.Cliente; import com.sistema.exceptions.ClienteJaCadastradoException; import java.util.ArrayList; public class ClienteService { private ArrayList<String> cpfsCadastrados = new ArrayList<>(); public void cadastrar(Cliente c) throws ClienteJaCadastradoException { if (cpfsCadastrados.contains(c.getCpf())) { throw new ClienteJaCadastradoException( "CPF já cadastrado: " + c.getCpf()); } cpfsCadastrados.add(c.getCpf()); System.out.println("Cadastrado: " + c.getNome()); } }
Main.java
package com.sistema; import com.sistema.model.Cliente; import com.sistema.service.ClienteService; import com.sistema.exceptions.ClienteJaCadastradoException; public class Main { public static void main(String[] args) { ClienteService svc = new ClienteService(); Cliente c1 = new Cliente("Maria", "123.456.789-00"); Cliente c2 = new Cliente("João", "123.456.789-00"); try { svc.cadastrar(c1); svc.cadastrar(c2); // mesmo CPF → exceção } catch (ClienteJaCadastradoException e) { System.out.println("Erro: " + e.getMessage()); } } }
Saída
Cadastrado: Maria Erro: CPF já cadastrado: 123.456.789-00

SistemaEmprestimoLivros miniprojeto
Implemente o esqueleto do Sistema de Empréstimo de Livros com pacotes organizados. Crie a entidade Livro, a exceção LivroIndisponivelException e o serviço BibliotecaService com os métodos emprestarLivro e devolverLivro.
Requisitos
Pacote base: com.biblioteca
Livro com atributos titulo, autor e disponivel
emprestarLivro lança LivroIndisponivelException se não disponível
devolverLivro marca o livro como disponível novamente
model/Livro.java
package com.biblioteca.model; public class Livro { private String titulo; private String autor; private boolean disponivel = true; public Livro(String titulo, String autor) { this.titulo = titulo; this.autor = autor; } public String getTitulo() { return titulo; } public String getAutor() { return autor; } public boolean isDisponivel() { return disponivel; } public void setDisponivel(boolean d) { disponivel = d; } }
exceptions/LivroIndisponivelException.java
package com.biblioteca.exceptions; public class LivroIndisponivelException extends Exception { public LivroIndisponivelException(String msg) { super(msg); } }
service/BibliotecaService.java
package com.biblioteca.service; import com.biblioteca.model.Livro; import com.biblioteca.exceptions.LivroIndisponivelException; public class BibliotecaService { public void emprestarLivro(Livro livro) throws LivroIndisponivelException { if (!livro.isDisponivel()) { throw new LivroIndisponivelException( "Livro indisponível: " + livro.getTitulo()); } livro.setDisponivel(false); System.out.println("Empréstimo realizado: " + livro.getTitulo()); } public void devolverLivro(Livro livro) { livro.setDisponivel(true); System.out.println("Devolvido: " + livro.getTitulo()); } }
Main.java — testando o sistema
package com.biblioteca; import com.biblioteca.model.Livro; import com.biblioteca.service.BibliotecaService; import com.biblioteca.exceptions.LivroIndisponivelException; public class Main { public static void main(String[] args) { Livro livro = new Livro("Clean Code", "Robert Martin"); BibliotecaService svc = new BibliotecaService(); try { svc.emprestarLivro(livro); svc.emprestarLivro(livro); // já emprestado → exceção } catch (LivroIndisponivelException e) { System.out.println("Erro: " + e.getMessage()); } svc.devolverLivro(livro); } }
Saída
Empréstimo realizado: Clean Code Erro: Livro indisponível: Clean Code Devolvido: Clean Code

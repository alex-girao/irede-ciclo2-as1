01
A pasta model em projetos Java convenciona conter as entidades do sistema — classes que representam os dados (ex: Cliente, Produto, Livro).
02
A pasta service em projetos Java é usada para armazenar a interface gráfica do usuário.
03
O uso de subpacotes (ex: com.empresa.sistema.model) organiza melhor projetos maiores, separando responsabilidades por camada.
04
import java.util.* importa todas as classes de java.util e também de todos os seus subpacotes.
05
O nome qualificado completo de uma classe inclui o seu pacote: por exemplo, java.util.ArrayList.
06
Pacotes em Java equivalem a namespaces em linguagens como C++ e C#, servindo para organizar e isolar nomes.
07
A pasta controllers convenciona conter classes que orquestram a comunicação entre as camadas do sistema (ex: ClienteController).
08
Em um projeto gerenciado pelo Maven, o código-fonte Java fica em src/main/java.
09
É recomendável colocar todas as classes do projeto em um único pacote para simplificar a organização.
10
O uso de pacotes melhora a manutenibilidade do código e facilita o trabalho em equipe, pois cada desenvolvedor pode trabalhar em seu pacote.
